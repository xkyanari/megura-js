# Privacy Policy

Last updated: 2026-08-20

This Privacy Policy explains how Dahlia, the Megura Discord bot, collects, uses, stores, and deletes data when people use Dahlia in Discord servers.

## What Dahlia is

Dahlia is a Discord bot for the Megura project. Dahlia provides server utilities and game features such as RPG profiles, progression, rewards, shops, auctions, battles, brawls, CAPTCHA/verification setup, temporary channels, and related server configuration tools.

Dahlia is designed to run without Discord privileged gateway intents. Dahlia does not request the privileged Message Content, Server Members, or Presence intents.

## Data Dahlia may process

Dahlia may process the following Discord data when users or server administrators interact with the bot:

* Discord user IDs
* Discord usernames or display names supplied through Discord interactions
* Guild/server IDs
* Channel IDs
* Role IDs
* Message IDs related to bot-created messages or configured bot features
* Interaction data from slash commands, buttons, select menus, and modals
* Timestamps related to bot activity, setup actions, and gameplay events

## Game and server data Dahlia stores

Dahlia stores data needed to operate its features, including:

* Player profiles and character names
* Player stats, levels, experience, balances, rewards, and inventory
* Shop purchases and special shop records
* Battle, duel, brawl, and arena activity
* Auction records, bids, auction items, and related timestamps
* Server setup settings such as configured channels, roles, rules, verification settings, shop settings, and feature toggles
* Wallet or account records when a feature explicitly asks a user to register that information

## Message content

Dahlia does not collect normal channel message text for commands, AI chat, deleted-message logging, or passive monitoring.

Legacy message-prefix commands and open channel AI chat are disabled. Users interact with Dahlia through explicit Discord interactions such as slash commands, buttons, select menus, and modals.

Message content is not used to train machine learning or AI models by Megura.

## Privileged intents

Dahlia does not request:

* Message Content Intent
* Server Members Intent
* Presence Intent

Gameplay and server features use data provided by user-initiated Discord interactions and administrator configuration.

## How Dahlia uses data

Dahlia uses stored data to:

* Create and maintain player profiles
* Track gameplay progression, rewards, balances, inventory, battles, brawls, auctions, and shop activity
* Run configured server tools such as verification, rules, roles, logs, channels, and feature toggles
* Prevent abuse, spam, repeated command misuse, and feature exploitation
* Troubleshoot errors and maintain the bot
* Respond to user and administrator support requests

## Data storage

Dahlia is hosted on infrastructure where its database also exists. Some Discord-related data is stored off-platform in that database so Dahlia can provide persistent bot features.

Access to production data should be limited to maintainers who need it to operate, maintain, secure, or support Dahlia.

## Retention

Local log files are automatically removed after 30 days.

Gameplay and server configuration records may be kept while they are needed to provide bot features, maintain player progress, support server setup, investigate abuse, or comply with valid requests.

If a server removes Dahlia or disables features, some related records may remain until cleanup or deletion is requested.

## User choices and opt-out

Users can stop creating new gameplay or activity records by not using Dahlia's gameplay commands and interactions.

Server administrators can disable configured bot features with `/setup disable` where supported.

Because Dahlia's game features require persistent player records, using those features may require storing Discord IDs and gameplay data.

## Deletion requests

Users can request deletion of their activity or player data through the support server listed by Dahlia's `/support` command.

Include your Discord user ID and, when relevant, the server/guild ID where the data was created so the request can be located.

Server administrators can request deletion of server configuration records for their server through the same support channel.

## Third-party services

Dahlia relies on Discord's platform and APIs. Dahlia may also use third-party infrastructure or service providers for hosting, storage, logging, and bot features.

Those services may process data according to their own terms and privacy practices.

## AI training

Message content and gameplay data are not used by Megura to train machine learning or AI models.

## Security

We use reasonable technical and administrative measures to protect Dahlia's data. No system can be guaranteed completely secure, and users should avoid submitting sensitive personal information through bot commands or modals unless a feature explicitly requires it.

## Changes to this policy

This Privacy Policy may be updated as Dahlia and Megura evolve. Continued use of Dahlia after changes are posted means you acknowledge the updated policy.

## Contact

For privacy questions, support, or data deletion requests, contact the Megura/Dahlia maintainers through the support server listed by Dahlia's `/support` command.
