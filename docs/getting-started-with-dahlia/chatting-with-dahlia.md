# 💬 Chatting with Dahlia

Dahlia's open channel AI chat is currently disabled so the bot can operate without Discord's privileged Message Content intent. She no longer reads normal server messages or responds when users call her name in a channel.

If conversational features return, they should use slash commands, buttons, modals, or another explicit interaction where the user intentionally submits text to Dahlia. This keeps the interaction transparent and avoids ambient message scanning.

{% hint style="warning" %}
Older examples that used "Dahlia ..." messages in a public channel are no longer supported.
{% endhint %}
