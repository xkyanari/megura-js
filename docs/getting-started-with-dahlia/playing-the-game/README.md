# 🎮 Playing the Game

The `/start` command will ask for your character name and create your player profile. Dahlia uses this name in game screens, dialogue, and profile displays. It also contains information on how to play the game. Once done, you can check your profile with `/profile`: it shows your Voyager ID card with your level, stats, gear and IURA, your faction, where you're exploring, and this week's quests, discoveries and faction points.

`/rankings` shows the server's leaderboards, one page each: duel wins, highest levels, monster kills, top earners (lifetime IURA), quests finished this week, places discovered, and faction points this week. Weeks run Monday to Sunday (UTC).

{% hint style="info" %}
Game features store player data such as your Discord user ID, guild ID, character name, level, experience, balances, inventory, purchases, battle results, brawl results, auction activity, and timestamps. See [Privacy and Data](../../privacy-and-data.md) for details.
{% endhint %}
