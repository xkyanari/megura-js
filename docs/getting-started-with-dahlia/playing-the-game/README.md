# 🎮 Playing the Game

The `/start` command will ask for your character name and create your player profile. Dahlia uses this name in game screens, dialogue, and profile displays. It also contains information on how to play the game. Once done, you can check your profile with `/profile`: it shows your Voyager ID card with your level, stats, gear and IURA.

{% hint style="info" %}
Game features store player data such as your Discord user ID, guild ID, character name, level, experience, balances, inventory, purchases, battle results, brawl results, auction activity, and timestamps. See [Privacy and Data](../../privacy-and-data.md) for details.
{% endhint %}
