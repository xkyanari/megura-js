# 🖥 For Developers

**Megura** is a community-driven project focused on delivering an engaging and immersive gaming experience to players. Dahlia is written in JavaScript on Node.js, with discord.js, MySQL and Redis.

The code is open source under the **GNU General Public License v3 or later**, so anyone can read, modify and share it under the same terms. Other developers can run their own version of the bot, customize it for their community, add features and create new gameplay. Contributions are welcome: see the repository's README for how to set it up and run the tests.
