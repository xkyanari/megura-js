# 💰 Subscription Models

**Project DAHLIA** helps Discord communities run an engaging text-based RPG alongside the server tools they need every day.

Each server is on one of the plans below. The exact set of features is configured per plan and may change as the game grows.

{% tabs %}
{% tab title="Free" %}
* Play the RPG: monsters, duels, brawls, quests and the global shop
* Verification with captcha
* Button roles, tickets and forms
{% endtab %}

{% tab title="Premium" %}
* Everything in Free
* Giveaways and raffles
* A special shop for the server's own rewards
{% endtab %}

{% tab title="Enterprise" %}
* Everything in Premium
* Scheduled posts and events
* Your own DAHLIA bot with your own name, logo and branding
* Your own lore and setting for the story
* Hosting with your own database for privacy
{% endtab %}

{% tab title="Megura" %}
* Everything in Enterprise
* Factions with their own roles
* Story events and the full Messinia Graciene storyline
{% endtab %}
{% endtabs %}

Early collaborators with Megura receive the Enterprise plan free of charge.
