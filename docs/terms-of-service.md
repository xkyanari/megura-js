Last updated: 2026-08-20

## What Dahlia does

Dahlia provides Discord server utilities and game features for the Megura project, including RPG profiles, progression, rewards, shops, auctions, battles, brawls, CAPTCHA/verification setup, temporary channels, and related server configuration tools.

Dahlia is designed to run without Discord privileged gateway intents. Dahlia does not scan normal channel conversations, presence activity, or the full server member list.
